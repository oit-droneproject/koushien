# Hula
　小型のドローンであり、100g以下であるため国土交通省で登録の必要がないドローンです。
最大飛行時間は約9〜10分、通信距離は約50m、最大高度は10mという仕様であり
専用アプリとPythonで制御することが可能です。


#### 公式サイト

https://redcliff-inc.co.jp/service/drone-sales-and-subscription/hula/

#### 専用アプリ
